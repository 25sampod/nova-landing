# NOVA — Build Better. Work Smarter.

A fully responsive, modern landing page for **NOVA**, a fictional AI productivity platform, built as a front-end development intern assignment.

## Project description
NOVA is a marketing landing page built to feel like a real enterprise product rather than a tutorial. It includes all 13 required sections (from the hero through pricing and FAQ) and a polished, responsive user experience.

## Technologies used
- **Next.js 16** (App Router) & **React 19**
- **TypeScript**
- **Tailwind CSS v4**

## Features
- **All 13 required sections** implemented.
- **All 8 bonus features** implemented (Dark/Light mode, Testimonial carousel, Pricing toggle, Demo modal, Newsletter API validation, Animated statistics, Scroll animations, Back-to-top button).
- **Responsive design** across mobile, tablet, and desktop.

## Installation instructions
```bash
npm install
npm run dev
```
